# API-2026-10-17-03：服务端查询没有玩家级策略视图

- 类别：已知限制（查询能力）
- 优先级：P2
- 状态：未安排改动
- 发现日期：2026-10-17
- 关联记录：无

## 证据

`ServerFilterQuery` 当前只提供 `Status` 和 `FilterStatus`。服务端状态视图包含全局选择与各类策略数量，不提供按玩家 UUID 查询策略的请求或结果视图。规范见 `../../Prismod_服务端_API_命令与协议.md` 的服务端 API 章节。

## 影响

服务端 API 使用者可以读取聚合状态，但无法通过公开查询接口诊断某个玩家的个人选择或覆盖策略。现有管理命令仍可按玩家提交操作，这不等于公开查询能力。

## 复现或验证步骤

由 sealed 查询类型和当前状态视图静态确认。没有玩家级查询可执行，因此尚无对应运行时验证。

## 处理

这是当前公开 API 的能力边界，不是运行故障。新增前需明确离线玩家、权限、数据生命周期和返回快照语义；当前不扩展 API。

## 修复与验证结果

无修复计划。若需求成立，再设计查询契约并覆盖在线/离线玩家、不可变视图及服务端线程安全测试。
