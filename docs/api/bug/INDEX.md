## 生命周期

- 每次新发现或复现都创建独立文件，不覆盖旧记录；同类问题再次发生时，在新记录中链接前次记录。
- 所有未解决问题的具体记录集中放在 `list/`；索引和模板留在本目录根部。
- 文件记录证据、影响、复现条件、处理决定、修复和验证结果；未验证的内容明确标注。
- 问题修复并验证后，将记录移入 [问题归档索引](archive/INDEX.md)，并同步更新本索引。只有记录已归档且再次复现，才创建关联它的新记录。
- 新记录按 `YYYY-MM-DD-API-序号-简短英文主题.md` 命名，使用 [问题记录模板](模板.md)。
