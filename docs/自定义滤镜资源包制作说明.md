# Prismod 统一资源包格式 v1

Prismod 只扫描 `config/prismod/resourcepacks/` 的直接子目录和 `.zip` 文件。这是 Prismod 私有格式，不是 Minecraft 原版资源包：不需要 `pack.mcmeta`，也不进入原版资源包界面。

模组内置滤镜也遵循相同的 v1 目录和清单约定，完整默认包源码位于 `src/main/resources/assets/prismod/custom/prismod_default_filters/`；该目录内包含包清单、`assets/prismod/filters/`、`assets/prismod/lang/` 和 `assets/prismod/runtime/`，与 TACZ 的 `assets/<mod>/custom/<默认包>` 形式一致。滤镜名称翻译必须随资源包放在 `assets/<namespace>/lang/`，不依赖模组外层语言文件；外层 `assets/prismod/lang/` 仅用于 Prismod 自身界面、按键和消息。

首次启动客户端时，模组会把内置包导出到 `config/prismod/builtin/prismod_default_filters/`，之后按普通目录资源包读取。导出只补齐缺失文件，不覆盖已有文件，因此可以直接编辑该目录中的默认滤镜；修改后使用 F3+T 或重新进入世界触发 Prismod 自己的重载。

旧版 `prismod.meta.json` 和 `assets/<namespace>/shaders/...` 自动扫描格式已废弃，不会自动转换。

## 1. 根清单与目录

根目录必须有 `prismod.pack.json`：

```json
{
  "schema": "prismod.resource_pack",
  "format_version": 1,
  "namespace": "example",
  "name": "示例滤镜",
  "filters": [
    {"id": "cinematic", "path": "assets/example/filters/cinematic"},
    {"id": "grayscale", "path": "assets/example/filters/grayscale"}
  ]
}
```

`namespace` 不能是 `minecraft` 或 `prismod`；`id` 必须是合法资源路径且不能重复；`path` 必须位于当前 namespace 的 `filters/` 下。未知字段在同一版本中忽略，清单之外的目录不会被读取。可选 `dependencies` 仍支持 Forge 模组版本范围。

```text
example-resource-pack/
├─ prismod.pack.json
└─ assets/example/
   ├─ filters/
   │  ├─ cinematic/filter.json
   │  └─ grayscale/
   │     ├─ filter.json
   │     ├─ post.json
   │     └─ program/{grayscale.json,grayscale.fsh,fullscreen.vsh}
   └─ lang/
      ├─ zh_cn.json
      └─ en_us.json
```

## 2. filter.json

每个滤镜目录必须有 `filter.json`。GLSL：

```json
{"schema":"prismod.filter","format_version":1,"type":"post_chain","display_name":"filter.example.grayscale","source":"post.json","default_strength":1.0}
```

LUT：

```json
{"schema":"prismod.filter","format_version":1,"type":"lut3d","display_name":"filter.example.cinematic","source":"lut.cube","color_space":"srgb","default_strength":1.0}
```

`display_name` 是必选翻译键；`default_strength` 可选且范围为 `0.0-1.0`；引用路径不能跨滤镜目录、namespace 或穿越路径。

语言文件是 JSON 对象，例如 `assets/example/lang/zh_cn.json`：

```json
{
  "filter.example.grayscale": "黑白"
}
```

资源包重载时，Prismod 会把当前语言和 `en_us` 的语言文件加载到自己的显示翻译表中；当前语言优先，缺少当前语言时回退 `en_us`。两个文件都没有该键时界面显示完整滤镜 ID（例如 `example:grayscale`）。这张翻译表只服务于 Prismod 滤镜 UI/F8 显示，不会注册到 Minecraft 全局 `LanguageManager`，也不会借用模组 `assets/prismod/lang/` 的滤镜键。

## 3. post_chain

`source` 指向当前滤镜目录下的 PostChain JSON。它必须包含一个 `swap` target 和一个 `minecraft:main -> swap` pass，且 pass 与 program 都必须声明 `Intensity` float uniform。program JSON 和 GLSL 只允许位于当前滤镜目录的 `program/` 下。

## 4. lut3d 与 .cube

Adobe `.cube` 必须是 3D LUT：`LUT_3D_SIZE 32`、32768 个 RGB 数据点、`color_space` 固定为 `srgb`。支持注释、`TITLE`、`DOMAIN_MIN`、`DOMAIN_MAX`；缺少域范围时使用 `0..1`。未知指令、尺寸或点数错误、非有限值和非法范围会拒绝滤镜。强度 0 为原画面，1 为完整 LUT，中间值为插值。

## 5. 导入、启用与重载

可以在 Prismod 的“资源包管理”页面拖入目录或 ZIP，也可以手动放入上述目录。保存后由 Prismod 私有资源管理器重新读取，不调用 Minecraft 原版资源包重载。错误 schema、版本、namespace、路径、重复 ID、损坏 ZIP 或缺少 `filter.json` 的资源包会被跳过；未知滤镜类型只跳过对应条目。
